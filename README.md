#项目理解
##经查阅资料，主控使用自带WIFI模块的ESP32较为合适，相较现有的STM32集成度更加高
##灯板材料预计使用WS2812CRGB灯珠，因其具有高亮度特点且使用5V供电，可以直接连接到ESP32最小系统板的5V输出端口
##灯板数量预计使用6个，即时针·分针·秒针显示各两块
##因原有12v转5v转3.3v模块，电源起初计划使用12V电池，后因体积原因决定使用3.7V电池板
